# FlightHub Architecture

This folder contains technical architecture documents for the FlightHub
platform. These files complement the business overview and runbooks:

- `system-architecture.md`: end-to-end system architecture, service ownership,
  request/event flows, deployment topology, observability, and production
  readiness notes.
- `interview-system-architecture.md`: shorter interview-ready architecture
  summary with a presentation-friendly architecture image and talking points.
- `assets/flighthub-system-architecture.svg`: reusable architecture image for
  GitHub, slides, README files, and PDF exports.

Mermaid diagrams render directly on GitHub and in most modern Markdown viewers.
