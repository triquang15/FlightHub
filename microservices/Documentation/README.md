# FlightHub Documentation

FlightHub documentation is organized by purpose:

| Area | Folder | Use when |
| --- | --- | --- |
| Architecture | `architecture/` | Explaining the system design, service topology, diagrams, data ownership, CI/CD, and observability. |
| Business overview | `business-overview/` | Reviewing what each service owns, does not own, and how it participates in production flows. |
| Guides and runbooks | `guide/` | Running local/dev/prod-like stacks, observability tools, Redis/Kafka usage, media storage, Flyway, and deployment planning. |
| SQL | `sql/` | Demo seed data, verification SQL, and migration support scripts. |

- `architecture/system-architecture.md`
- `business-overview/README.md`
- `guide/local-full-stack-runbook.md`
- `guide/docker-production-runbook.md`
- `guide/production-deployment-plan.md`
